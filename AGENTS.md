# Agent rules

- English only in code, comments and docs. User-facing UI text is Spanish, in `src/strings.ts`.
- Docs: living docs in `docs/*.md`, decisions in `docs/adr/`, coding plans in `docs/plans/`, todos/brainstorms in `docs/notes/`. No `.md` files elsewhere.
- Save every coding plan to `docs/plans/YYYY-MM-DD-slug.md` before implementing.
- Every plan ends with a docs step: update affected `docs/*.md`, add ADRs for significant decisions, update `docs/adr/README.md`.
- One fact, one place: link, don't copy.
