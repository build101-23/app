# Menus in calendar order from tomorrow, and what the list costs per day

Status: **done** in code; the web app (with the v3 redesign) and then the function deploy are pending, in that order.

## Context
- [ADR 0024](../adr/0024-agent-builds-the-menu-from-real-products.md) (real prices) already lets a menu cover 1 to 7 days, each once, the whole week otherwise. But the chat doesn't know what day it is, and the Menu tab sorts days Monday-first.
- Asked for:
  - A week stays the default, but in the chat you can ask for fewer days ("planificame los 3 días que vienen"), for a smaller plan and a smaller list.
  - The plan knows which days those are: asked on a Friday, 3 days are sábado, domingo and lunes.
  - When the list's price is given, also what it comes to per day: the total ÷ the menu's days.
- Decided with the user:
  - Plans start tomorrow unless they say otherwise ("desde hoy", "desde el lunes").
  - 1 to 7 days. Asked for more, the chat builds the week and says a week is the most.

## Design
- **Weekday keys in calendar order.** Each day comes after the one before, counting from the first (sunday, then monday), gaps fine, never twice. The array order is the display order, so the Menu tab and the chat's preview stop sorting Monday-first.
- **Today's date reaches the chat** as a `<today>` block in the user message ("Saturday, October 17, 2026", Montevideo's date), sent only when it differs from the last one the chat saw, like `<saved_profile>`. The system prompt stays frozen. The web app hides the block.
- **The prompt**:
  - A week unless the user asks for fewer days, and it never asks how many.
  - It starts tomorrow, and its first line names the days. On a first menu with no length given, that line adds that they can ask for fewer.
  - Fewer recipes for fewer days.
  - Meal changes keep the saved days; a new plan or a new length starts tomorrow again.
  - Asked about a day the menu doesn't have, it says which days the menu covers and offers a new one.
  - Whenever it says the total, it says the per-day amount too.
  - "Arranco semana nueva" clears the marks, never the menu.
  - "Week" becomes "menu" across the prompt, the tool texts and `listLines`.
- **Per day**:
  - In `verdict` (the price answer the model reads): the base total ÷ the days.
  - On the screens: the chosen total ÷ the days, as "$ 277 por día · menú de 7 días", under the total in the chat's list card and under the store choice in the List tab.
  - Like the total, it counts what's left to buy.
  - Not shown for a 1-day menu, or when there's no chosen option.
