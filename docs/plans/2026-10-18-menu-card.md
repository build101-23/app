# A better menu card in the chat

## Context
When the chat saves or shows the menu it adds a card under the reply. Today that card is an assistant bubble holding a text wall: each day's name, then its four recipe names joined with " · ", which wraps to three lines. A week is 723 px tall at 390 px wide, it has no hierarchy, and it looks like more chat text rather than a result. The user finds it ugly and wants a modern but minimal version that doesn't feel forced.

## Approach
Same data, same button, a structured card instead of a bubble full of text. `MenuPreview` in `src/Menu.tsx`, styles in the chat section of `src/index.css`. No new token or dependency.
- **Header:** a 32 px sunk-surface circle with the Menú calendar icon (the dock's own icon, so the card is recognizably "the menu"), the title "Tu menú" at 650, and a pill on the right with the length ("7 días").
- **Rows:** one per day, in saved order, under hairlines like the Menu tab's: the day's first three letters in a muted fixed-width column (Lun, Mar…), and its meals in ink, clamped to two lines with an ellipsis. The full names are in the Menu tab, one tap away; for screen readers the row says the whole day.
- **Footer:** the same secondary "Ver menú" pill with a trailing arrow (the chevron, turned).
- **Card, not bubble:** surface fill, 1px line, the card's 16px radius, up to 28rem wide, with the usual `rise-in`. It no longer carries the bubble's tail, which belongs to a speaker.
- Nothing is colored: no tangerine (The One Rule), no new fills. The look comes from hierarchy, spacing and the icon circle.

Not changed: when the card appears, the list card (still a bubble), the Menu tab. The list card will look plain next to this one; that's a follow-up if wanted.

## Check
`npm run dev:fixture` (the default long chat has a 7-day card; `?menu=short` has 3 days) at 390 px and wide, in light: heights before and after, long recipe names clamped, the button disabled while a reply is saving. `npx tsc -b`, `npm run lint`, `npm run build`.

## Docs
`docs/design.md`: the "Menu card" bullet in Chat, and the icons paragraph if the arrow is new.

## Results
- Built as planned: `MenuPreview` in `src/Menu.tsx`, the `.menu-card` styles in `src/index.css`, and the `menuCard` strings.
- Checked in `npm run dev:fixture` at 390 px in light: the 7-day card went from 723 px to 565 px and now has a header, hairlines and a footer; the 3-day card (`?menu=short`) is 313 px. At 645 px wide the card stops at 448 px (28rem). `npx tsc -b` and `npm run lint` pass.
- Known limits: the two-line clamp cuts a long day mid-word with an ellipsis, and the fixture's days all repeat the same four recipes, so the real data will look more varied. The list card next to it is still a plain bubble.
- Not checked: the button's disabled look while a reply is saving (it's the standard `.button:disabled`), a real screen reader, and Safari.
- Options if it's still too tall: show only the first three days with a "y 4 días más" row, or show the first meals followed by "+N" instead of the ellipsis.
